## موارد باز و محدودیت‌های تأیید
1. Build و انتشار آنلاین در این مرحله تأیید نشده‌اند. برای commitهای جدید، GitHub Combined Status هیچ check ثبت‌شده‌ای برنگرداند؛ لینک‌های عمومی GitHub Pages نیز در بررسی وب قابل دسترسی نبودند. بنابراین ثبت commit را نباید معادل انتشار موفق دانست.
2. مخزن‌های Vercel بر اساس راهنمای داخل مخزن قرار است توسط پلتفرم Build/Deploy شوند؛ اجرای Build و بررسی Preview پس از این تغییرات هنوز نیازمند تأیید است.
3. در `sapphire-bird-palm-drift` فایل `.github/workflows/static.yml` مسیر ریشه مخزن را بدون Build منتشر می‌کند، درحالی‌که فایل `index.html` در ریشه موجود نیست. مسیر GitHub Pages باید جداگانه تعیین تکلیف شود؛ راهنمای داخل مخزن Vercel را مقصد استقرار معرفی می‌کند.
4. مخزن `swift-grove-pixel-brick` با نام تجاری «نقش‌چرم» یک وب‌سایت مفهومی جداگانه است. محتوای آن شامل ادعاهای تأییدنشده درباره دوره ۸ هفته‌ای، ۱۶ جلسه، ظرفیت ۱۸ نفر، چرم گیاهی/کرومی، ضخامت‌های عمومی و تصاویر/ابعاد گالری است؛ فرم ثبت‌نام نیز فقط در حافظه محلی مرورگر ذخیره می‌کند. به‌دلیل احتمال تفاوت هویت و نبود تأیید مؤلف، این مخزن در این مرحله تغییر داده نشد و پیش از انتشار باید وضعیت رسمی آن و محتوای گالری تأیید شود.
5. تصاویر واقعی آثار مؤلف برای Hero و گالری‌ها هنوز از آرشیو تصویری پروژه بازیابی و تطبیق نشده‌اند. تصاویر نمایشی یا تولیدشده نباید به‌عنوان آثار واقعی مؤلف معرفی شوند.
