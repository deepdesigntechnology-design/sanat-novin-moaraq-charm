# شماتیک‌های آموزشی صنعت نوین معرق چرم

این پوشه برای نگهداری تصاویر شماتیک آموزشی کتاب و سایت در نظر گرفته شده است.

## فایل‌های مورد نیاز (نام‌های پیشنهادی):

| نام فایل | توضیح |
|----------|--------|
| `motif-single.jpg` | موتیف تک‌قطعه (زیبایی شکلی و گل) |
| `motif-production.jpg` | تولید موتیف با دستگاه پرس صنعتی یا سی‌ان‌سی لیزر |
| `motif-relief.jpg` | موتیف با نقش برجسته حکاکی‌شده |
| `motif-shamseh.jpg` | چیدمان شمسه‌ای و تکرارپذیری موتیف‌ها |
| `three-base-lines.jpg` | سه خط پایه اسلیمی (ربع‌دایره، نیمه‌گرد، اس‌شکل) |
| `golden-points.jpg` | نقاط طلایی کادر + Super Gold Point |
| `classical-composition.jpg` | ترکیب‌بندی کلاسیک ایرانی (ترنج + لچک + گوشه + حاشیه) |

پس از آپلود فایل‌ها با نام‌های بالا، تصاویر به‌طور خودکار در صفحه تکنیک‌ها نمایش داده می‌شوند.
